# MCP Support

FleetLink MCP server for agent interaction.

- Auth via user-created agent tokens (from dashboard).
- Tools: upload file/directory, list shares, delete, renew, get metadata, etc.
- Compatible with the fleet-share CLI patterns.
- Enabled after multi-user cutover with passkeys + per-user tokens.
- Configurable by admin through Infisical settings.

This restores the MCP capability from the original architecture.
